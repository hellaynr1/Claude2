# Daily plan

1. Read everything I list. Ask one question only if a deadline or priority is truly unclear.
2. Sort tasks into:
   - **Must do today** (deadlines, things others are waiting on), at most 3
   - **Should do** if there's time
   - **Later** (move these off today)
3. For each Must-do, write the very first concrete step (5 minutes or less).
4. Suggest a rough order for the day with focus blocks of 25–50 minutes and short breaks.
5. Keep the whole plan under 15 lines.
