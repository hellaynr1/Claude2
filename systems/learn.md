# Workflow: learn
Merges: learning-tracker, optimizer teaching coach, Learn tab. Skill: `learn`.

| Contract | |
|---|---|
| **Inputs** | a question or "teach me X"; `learning/progress.md`; app Learn data (export) |
| **Outputs** | intermediate-level lesson with 1–2 free primary resources + an exercise; progress (Learning now → Learned) in `learning/progress.md` and the app; 3 daily objectives; spaced reviews at 1/3/7/21 days |
| **Steps** | read progress + "How I learn best" → teach compactly (no beginner fluff) → exercise/quiz → mark learning/learned only on evidence (explained back, quiz passed) → schedule reviews → note new learning-style facts |
| **Failure modes** | lessons that never lead to "learned"; generic content; reviews skipped |
| **Approval point** | none |
| **Metric / target** | topics learned ≥8 by 2026-11-14; review pass rate ≥80%; daily goal met ≥4 days/week |
| **Kill criterion** | n/a (core). Change the lesson format if 0 topics learned after 2 weeks |
