# System: research-to-brain

**Trigger:** "look up", "research", "what's the best…"
**Roles:** researcher, teacher
**Skills & tools:** web search, video-notes (for videos), web-data (for data), Second Brain

**Steps**
1. Search; prefer official and independent sources; note which sources are vendors selling something.
2. Explain the answer simply, with sources linked.
3. Save it to the brain: add stars to `app/knowledge.json` (fields: id `r-…`, c `research`/`lessons`/`tools`, t title, d date, s 2–3 sentence summary, x key points, l related ids, url source). Commit + push: the web app shows them on every device. Public facts only; anything about my businesses or private life goes to the Obsidian vault.
4. Deep topics: use the built-in `anthropic-skills:deep-research` skill first, then save the key findings as above (one star per finding, max ~8).

**Done when:** the answer is explained, sourced and saved.
