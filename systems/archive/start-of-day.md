# System: start-of-day

**Trigger:** "start my day", "what's today", "plan today"
**Roles:** chief of staff, coach
**Skills & tools:** daily-plan, learning-tracker, personal-intelligence

**Steps**
1. Read `learning/progress.md` (Today's objectives, due spaced reviews), `memory/DECISIONS.md` (PROPOSED items waiting for a yes), project files' **Next step**, and open pull requests (daily research, optimizer).
2. Output one short plan (max 12 lines): 3 top tasks across projects, today's 3 learning objectives + reviews due, decisions waiting for you, pull requests to merge or close.
3. Mark the time budget: learning goal (minutes) + work blocks.
4. Save today's objectives to `learning/progress.md` if they changed.

**Done when:** you have one plan you can start on in 30 seconds.
