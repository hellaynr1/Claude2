# System: sync-everything

**Trigger:** automatically after any build or change, or "save this"
**Roles:** archivist
**Skills & tools:** GitHub (this repo), Google Drive connector, Second Brain artifact

**Steps**
1. Second Brain: add or update stars in the right color (the `BASE` list), republish to the same link.
2. Google Drive: put files in the right project folder (`@ Guidify LLC / <brand>/...`) or the Obsidian vault; create folders if missing.
3. Repo: save sources (`projects/`, `brand/`, `systems/`), add a dated entry to `brain/log.md`, update CLAUDE.md or a skill if a rule or how-to changed.
4. Commit and push. Personal details stay out of the repo while it's public.
5. Tell the owner in one line what was saved where.

**Done when:** all three places match.
