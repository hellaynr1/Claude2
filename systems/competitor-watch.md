# System: competitor-watch

**Trigger:** "check competitors", "what are others doing", monthly review.
**Roles:** market researcher, strategist, reviewer
**Skills & tools:** web search, web-data (public stats only, no scraping behind logins), reviewer

**Steps**
1. Read `memory/projects/investedia-competitors.md` (or the project's competitor file).
2. For each competitor: traffic estimate (same source + month for all), new features, content formats that perform, newsletter/social size. Mark every number with source and date; say when it's an estimate.
3. Find 1–3 things they do that we can copy or beat cheaply; rank by impact ÷ effort.
4. Update the competitor file, add a Reports line, and a research star only for a genuinely new insight.

**Done when:** the table is current and there are 1–3 ranked actions.
